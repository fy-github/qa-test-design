# AI Output Review

Use this reference when the artifact was generated by AI.

## Nine Risk Classes

### 1. Factual

Check whether facts, numbers, entities, dates, and rules are true.

### 2. Logical

Check whether the artifact contradicts itself or the source material.

### 3. Semantic

Check whether domain terminology is used correctly.

### 4. Source

Check whether references, citations, and claimed origins are real and correctly attributed.

### 5. Instruction Following

Check whether format, quantity, exclusions, and explicit user constraints were followed.

### 6. Structure

Check whether mandatory fields, tables, sections, and hierarchy are complete and stable.

### 7. Context Retention

Check whether important source information was ignored, replaced, or forgotten.

### 8. Duplication

Check whether content repeats itself or inflates apparent coverage.

### 9. Culture / Common Sense

Check whether the artifact violates obvious real-world expectations or local conventions.

## Automation-Friendly Checks

Suitable for automation:

- fact lookup
- field completeness
- format validation
- duplicate detection
- section presence

Must keep human judgment:

- business correctness
- release safety
- logical adequacy
- whether the artifact is decision-grade or only draft-grade
